# NFA → DFA Converter & Benchmark

Проект на C++ для преобразования регулярных выражений в:

- НКА (недетерминированный конечный автомат)
- ДКА (детерминированный конечный автомат)
- минимизированный ДКА

Также проект содержит систему бенчмаркинга для анализа производительности алгоритмов.

---

# Возможности

- Построение НКА по регулярному выражению
- Преобразование НКА → ДКА
- Минимизация ДКА
- Генерация случайных регулярных выражений
- Измерение времени выполнения
- Подсчёт количества состояний
- Экспорт автоматов в формат Graphviz DOT

---

# Используемые алгоритмы

## Построение НКА

Используется алгоритм Томпсона:
- конкатенация
- объединение (`|`)
- звезда Клини (`*`)

---

## Детерминизация

Используется subset construction:
- ε-замыкание
- переходы `move`
- построение множеств состояний

---

## Минимизация ДКА

Используется алгоритм разбиения состояний:
- удаление недостижимых состояний
- разбиение на классы эквивалентности
- объединение неразличимых состояний

# Сложность алгоритмов

| Этап | Время | Память |
|---|---|---|
| Регулярное выражение → НКА | O(n) | O(n) |
| НКА → ДКА | O(2^s · k) | O(2^s) |
| Минимизация ДКА | O(k · m²) | O(m²) |

Где:
- `n` — длина регулярного выражения
- `s` — число состояний НКА
- `m` — число состояний ДКА
- `k` — размер алфавита
